# Luxpower Data Visualizer

Современная веб-панель мониторинга и визуализации данных для гибридных инверторов **Luxpower** (включая SNA 5000 / SNA 6000 Wide PV и другие модели экосистемы Luxpowertek).

---

## ⚡️ Возможности

- **Интерактивная диаграмма мощности (Power Flow)**:
  - Отображение потоков энергии в реальном времени между Солнечными панелями, Сетью 220V, Инвертором, Домашней нагрузкой и Аккумулятором (BESS LiFePO4).
  - Анимированные линии направления тока с динамической цветовой индикацией (заряд — зеленый, разряд — красный/розовый, сеть — красный, потребление — янтарный).
  - Полноразмерный интерактивный вид для десктопа (1200px+) и оптимизированная карточная схема для мобильных устройств.
- **Инструментальные карточки (KPI)**:
  - **Таймер источника питания**: отображает непрерывный аптайм («Від батареї» / «Від мережі») с тикающим в реальном времени счетчиком и суммарной статистикой за последние 24 часа.
  - **Прогноз времени работы от батареи**: оценка оставшегося времени работы (`~Xг Yхв`) на основе фактического темпа разряда и среднего потребления дома со времени отключения сети.
  - Мониторинг SOC %, мощности заряда/разряда, напряжения, тока и температуры инвертора/АКБ.
- **Графики и аналитика за 24 часа**:
  - Суточный профиль баланса мощности с возможностью выделения диапазона для расчета суммарной энергии (кВт·год).
  - Графики работы батареи (SOC, ток, напряжение BMS, температура).
  - Мониторинг параметров сети и нагрева радиаторов инвертора.
- **Журнал телеметрии**:
  - Полная таблица с поиском и пагинацией по 90+ параметрам телеметрии.
  - Экспорт в CSV.
- **Гибкая авторизация (Luxpower Cloud)**:
  - Автоматическая работа из `.env` (для персональных инсталляций).
  - Вход через модальное окно с выбором сервера (`eu.luxpowertek.com`, `server.luxpowertek.com`, `us.luxpowertek.com`) и сохранением сессии в `localStorage` (готовность к развертыванию на GitHub Pages).
- **Интерфейс**:
  - Полная двуязычная поддержка (UA / EN).
  - Темная и светлая темы оформления.

## 🛠 Технологический стек

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Apache ECharts.
- **Backend / Gateway**: Node.js, Express, Axios.
- **Инфраструктура**: Docker, Docker Compose, Traefik reverse proxy.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/kirill-talk/luxpower-data-visualizer.git
cd luxpower-data-visualizer
```

### 2. Настройка переменных окружения (опционально)
Создайте файл `.env` в корне проекта (если хотите использовать авто-вход):
```env
LUX_BASE_URL=https://eu.luxpowertek.com
LUX_ACCOUNT=your_luxpower_login
LUX_PASSWORD=your_luxpower_password
PORT=3001
```
*Если данные не указаны в `.env`, веб-интерфейс предложит войти через форму авторизации и сохранит сессию в вашем браузере.*

### 3. Запуск через Docker Compose (рекомендуется)
```bash
docker compose up -d --build
```
Приложение будет доступно на `http://localhost:3000` (или через ваш настроенный домен / reverse proxy).

### 4. Локальный запуск для разработки

**Backend:**
```bash
npm install
npm run dev
```

**Frontend:**
```bash
cd client
npm install
npm run dev
```
