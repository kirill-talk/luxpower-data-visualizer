# Luxpower АКБ — Виджет для Android

Нативное приложение-виджет для рабочего стола Android, которое показывает текущий заряд аккумулятора (**SOC %**) и напряжение батареи (**В**) вашего инвертора Luxpower.

## Возможности

- Крупное отображение процента заряда (`SOC %`) с цветовой индикацией (`≥ 50%` — зелёный, `25–49%` — жёлтый, `< 25%` — красный) и горизонтальной шкалой.
- Отображение напряжения аккумулятора (`vBat`, В).
- Нажатие на виджет или кнопку `↻` принудительно обновляет данные.
- Кнопка `⚙` открывает настройки подключения.
- Автоматическое фоновое обновление каждые 15 минут через `WorkManager` (при наличии сети).

## Как скачать и установить APK

1. Откройте вкладку **Actions** в репозитории GitHub и выберите workflow **Build Android Widget APK** (можно запустить вручную кнопкой **Run workflow**).
2. После завершения сборки скачайте артефакт **`luxpower-battery-widget-apk`** и распакуйте файл `luxpower-battery-widget.apk`.
3. Скопируйте APK на телефон Android и установите (при необходимости разрешите установку из неизвестных источников).

## Настройка и добавление на экран

1. Откройте приложение **Luxpower АКБ** (или добавьте виджет на главный экран — окно настроек откроется автоматически):
   - **Через облачный прокси (по умолчанию):** оставьте `https://luxpower-proxy.kirill-talk.workers.dev/api`, введите логин и пароль от LuxpowerTek. Серийный номер (`SN`) подтянется автоматически при первом входе.
   - **Через собственный сервер:** укажите `https://<ваш-домен>/api` (если в `.env` сервера уже настроены учётные данные или донгл, логин и пароль можно оставить пустыми).
2. Нажмите **«Сохранить и обновить виджет»** — приложение проверит соединение и покажет актуальные `SOC %` и `В`.
3. Удерживайте палец на свободном месте рабочего стола Android → **Виджеты** → **Luxpower АКБ** и перетащите виджет на экран.
